# FreeSync - Windows 文件夹同步助手

![License](https://img.shields.io/badge/License-MIT-blue.svg)
![Platform](https://img.shields.io/badge/Platform-Windows-lightgrey.svg)
![C++](https://img.shields.io/badge/C++-17-blue.svg)

FreeSync 是一款轻量、快速的 Windows 文件夹同步工具，使用现代 C++17 开发。主要用于在两个文件夹之间同步文件、文件夹和删除操作，确保你的重要数据随时都有备份。

## ✨ 主要特性

*   **单向同步**：源文件夹 -> 目标文件夹，适合单向备份。支持可选的“同步删除”功能，保持目标文件夹与源文件夹完全一致。
*   **双向同步**：源文件夹 <-> 目标文件夹，适合多设备或多位置协同工作，新增、修改、删除操作均会双向同步。
*   **实时同步**：后台监听文件夹变化，一旦有文件变动立即自动同步，告别手动操作。
*   **智能盘符恢复**：专为 U 盘和移动硬盘设计。即使重新插入后盘符改变（例如从 E: 变成了 F:），软件也能自动识别并恢复同步任务。
*   **后台静默运行**：支持最小化到系统托盘，默默在后台为你守护数据安全。
*   **拖拽支持**：支持直接拖拽文件夹或文件到任务窗口，快速添加任务。

## 🖥️ 运行环境

*   **操作系统**：Windows 10 (版本 1703 或更高) / Windows 11
*   **架构支持**：x86 (32位) / x64 (64位)
*   *注意：由于使用了较新的 API 和 C++17 特性，不支持 Windows 8.1 及更早的操作系统。*

## 🚀 快速开始

1.  **添加任务**：点击主界面的 `➕` 按钮。
2.  **选择目录**：设置你的“源文件夹”和“目标文件夹”（可以直接将文件夹拖入窗口）。
3.  **配置选项**：
    *   需要双向修改？勾选 **双向同步**。
    *   需要目标目录和源目录一模一样？单向同步时勾选 **同步删除文件**。
4.  **执行同步**：
    *   点击 **手动同步** 立即执行一次。
    *   或勾选 **实时同步**，让它自动在后台工作。

## 💡 典型使用场景

*   **💻 工作资料备份**：单向同步 + 实时同步，将工作目录实时备份到移动硬盘。
*   **🔄 多设备协同**：双向同步，公司电脑和家里电脑通过移动硬盘保持资料双向最新。
*   **NAS 数据归档**：单向同步，将本地收集的照片和文档自动推送到网络共享盘。

## ⚠️ 注意事项

*   开启“双向同步”或“同步删除”前，请务必确认两个目录中的内容，以免发生误删除。
*   如果文件正被其他程序（如 Word、Excel）独占打开，可能会导致该文件同步失败，关闭占用程序后重试即可。
*   请勿使用多个同步工具同时监控并操作同一对文件夹，以免产生冲突。
