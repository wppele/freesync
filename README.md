FreeSync 是一款轻量、快速的 Windows 文件夹同步工具，使用现代 C++17 开发。主要用于在两个文件夹之间同步文件、文件夹和删除操作，确保你的重要数据随时都有备份。

当前版本：**v26.0611**

## ✨ 主要特性

*   **单向同步**：源文件夹 -> 目标文件夹，适合单向备份。支持按任务开启“安全删除”，保持目标文件夹与源文件夹一致。
*   **双向同步**：源文件夹 <-> 目标文件夹，适合多设备或多位置协同工作，新增、修改、删除操作均会双向同步。
*   **任务级配置**：每个任务都可以单独设置双向同步、安全删除、实时同步，不再要求所有任务使用同一策略。
*   **实时同步监控**：后台监听启用实时同步的任务；监控运行中仍可手动同步未启用实时同步的任务。
*   **安全删除回收区**：需要删除的文件会先移动到 `.freesync-trash`，保留原相对路径，并自动清理超过 7 天的回收目录。
*   **智能盘符恢复**：专为 U 盘和移动硬盘设计。即使重新插入后盘符改变（例如从 E: 变成了 F:），软件也能自动识别并恢复同步任务。
*   **后台静默运行**：支持最小化到系统托盘，支持开机自动运行并隐藏到托盘。
*   **拖拽支持**：支持直接拖拽文件夹或文件到任务窗口，快速添加任务。
*   **同步诊断日志**：日志会记录复制原因、文件大小差异等信息，便于排查同步行为。

## 🆕 v26.0611 更新内容

*   **界面优化**：主界面重新整理任务列表、日志、进度和状态显示，新增“同步选中”“同步全部”等更明确的操作入口。
*   **最近结果列**：任务列表会显示每个任务最近一次同步结果，例如“成功：复制 1，删除 0，失败 0”。实时同步触发后也会更新该列。
*   **任务右键菜单**：任务列表支持右键同步、编辑、删除；支持 Enter 编辑、Delete 删除。
*   **托盘菜单增强**：托盘右键支持显示窗口、同步全部、启动/停止实时同步监控、退出程序。
*   **开机自启动**：勾选“开机自动运行”后会写入用户启动项，并以最小化到托盘方式启动。
*   **任务级安全删除与实时同步**：添加/编辑任务时可单独勾选“同步删除文件”和“实时同步”。
*   **实时同步行为修正**：启动实时同步监控后，只锁定添加、编辑、删除任务；未开启实时同步的任务仍可手动同步。
*   **同步全部策略修正**：实时同步监控运行中，“同步全部”只同步未开启实时同步的任务。
*   **实时同步索引修复**：修复部分任务未开启实时同步时，监控句柄和任务索引可能错位的问题。
*   **安全删除增强**：单向/双向同步删除都统一移动到 `.freesync-trash`，日志显示完整回收路径。
*   **回收区说明文件**：`.freesync-trash` 根目录会生成 `请先阅读.txt`，说明该目录可在确认后手动清理。
*   **自动清理回收区**：超过 7 天的时间戳回收目录会在同步或启动监控前自动清理。

## 🖥️ 运行环境

*   **操作系统**：Windows 10 (版本 1703 或更高) / Windows 11
*   **架构支持**：x86 (32位) / x64 (64位)
*   *注意：由于使用了较新的 API 和 C++17 特性，不支持 Windows 8.1 及更早的操作系统。*

## 🚀 快速开始

1.  **添加任务**：点击主界面的 **添加任务**。
2.  **选择目录**：设置你的“源文件夹”和“目标文件夹”（可以直接将文件夹拖入窗口）。
3.  **配置选项**：
    *   需要双向修改？勾选 **双向同步**。
    *   需要目标目录和源目录一模一样？勾选 **同步删除文件**，文件会先进入安全删除回收区。
    *   需要后台自动监听？按任务勾选 **实时同步**。
4.  **执行同步**：
    *   点击 **同步选中** 同步当前任务。
    *   点击 **同步全部** 同步所有可手动同步的任务。
    *   勾选 **启动实时同步监控**，让启用实时同步的任务自动在后台工作。

## 💡 典型使用场景

*   **💻 工作资料备份**：单向同步 + 实时同步，将工作目录实时备份到移动硬盘。
*   **🔄 多设备协同**：双向同步，公司电脑和家里电脑通过移动硬盘保持资料双向最新。
*   **NAS 数据归档**：单向同步，将本地收集的照片和文档自动推送到网络共享盘。

## ⚠️ 注意事项

*   开启“双向同步”或“同步删除文件”前，请务必确认两个目录中的内容。
*   “同步删除文件”会先移动到 `.freesync-trash`，但超过 7 天的回收目录会自动清理。
*   如果文件正被其他程序（如 Word、Excel）独占打开，可能会导致该文件同步失败，关闭占用程序后重试即可。
*   请勿使用多个同步工具同时监控并操作同一对文件夹，以免产生冲突。
